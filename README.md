# A Minecraft Clone
This is my attempt at making a Minecraft clone. It is made using OpenGL in C++23. 

My goal with this project is to learn OpenGL, as well as graphics programming in general. The project uses cmake as a build system. If you are on a Linux system, you can do this:

```shell
cmake -S. -Bbuild
cmake --build build
```

To run the application, just run the created `MinecraftClone` executable.
